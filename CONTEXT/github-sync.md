# GitHub Sync Context

The GitHub repository is private by default.

## Sync Policy

- Use local milestone/manual pushes.
- Do not blind auto-commit or blind auto-push.
- GitHub Actions run on push, pull request, and a scheduled health check.
- CI must not store private source credentials or raw playback URLs.

## Expected Remote

The expected remote is a private GitHub repository under the authenticated
`EkaEva` account unless a later decision records a different owner.
