# Licensing Context

The project prefers permissive dependencies and source material.

## Allowed By Default

- MIT
- Apache-2.0
- BSD
- ISC

## Forbidden By Default

- GPL
- AGPL
- SSPL
- Unknown license
- No-license code
- Copied snippets without provenance

Every direct dependency, runtime asset, copied asset, generated source, or
substantial implementation reference must be recorded in
`third_party/SOURCES.md`.
